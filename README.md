# Web Portfolio

A modern, responsive portfolio website to showcase your engineering and design skills.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy to Customize**: Simple HTML structure with placeholder content
- **Interactive Navigation**: Smooth scrolling and mobile hamburger menu
- **Contact Form**: Built-in contact form (requires backend integration for full functionality)

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About Me**: Professional background and personal information
3. **Skills**: Display your technical skills organized by categories
4. **Projects**: Showcase your featured projects with descriptions and links
5. **Contact**: Contact form and contact information
6. **Footer**: Quick links and social media connections

## How to Use

1. **Open the portfolio**: Simply open `index.html` in your web browser
2. **Customize content**:
   - Edit `index.html` to update text, add your name, projects, skills, etc.
   - Modify `styles.css` to change colors, fonts, or layout
   - Update `script.js` to add custom functionality
3. **Add images**: Replace placeholder text with actual images for projects and profile
4. **Deploy**: Upload the files to any web hosting service (GitHub Pages, Netlify, Vercel, etc.)

## Customization Guide

### Update Personal Information
- Change "Your Name" in the hero section
- Update email, phone, and location in the About and Contact sections
- Add your actual social media links in the footer

### Add Projects
- Replace project placeholders with your actual projects
- Add project images, descriptions, and links
- Update technology tags to match your stack

### Modify Skills
- Edit the skill cards to match your expertise
- Add or remove skill categories as needed
- Update skill tags with your technologies

### Styling
- Colors: Modify CSS variables in `:root` section of `styles.css`
- Fonts: Change the font-family in the body selector
- Layout: Adjust grid settings and spacing as needed

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- No dependencies or frameworks required
